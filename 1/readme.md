# 네트워크 및 IT 인프라 기초 정리

## 1. 기본 개념 및 IT 하부구조

### 서버와 클라이언트

* **서버 (Server):** 정보를 제공하는 역할
* **클라이언트 (Client):** 정보를 요청하는 역할

### IT 하부구조 구성요소

* 하드웨어, 소프트웨어, 데이터센터, 클라우드 서비스, 네트워크

### 클라우드 서비스

* 물리적 하드웨어를 직접 소유·관리할 필요 없이, 전문 기업의 데이터센터 자원을 인터넷으로 필요한 만큼 빌려 쓰는 기술
* **SaaS (Software as a Service):** 인터넷을 통해 웹 브라우저로 접속해 이용하는 소프트웨어 서비스 (월세/구독 방식)

## 2. 정보 보안 개요

### 정보 보안의 3대 요소 (CIA Triad)

* **기밀성 (Confidentiality):** 인가된 사용자만 접근 허용
* **무결성 (Integrity):** 정보가 변조되지 않고 정확함 유지
* **가용성 (Availability):** 인가된 사용자가 필요할 때 언제든 접근 가능

### 보안 구분의 3가지 영역

* **관리적 보안:** 보안 정책, 절차, 교육, 조직 관리
* **물리적 보안:** 출입 통제, 데이터센터 보호, 재해 대책
* **기술적 보안 (주요 학습 영역):**
* **네트워크 보안:** 스위칭/라우팅 보안, 접근제어정책, VPN, NAT, IDS, NMS, 방화벽(Firewall), DDoS 대응 등
* **시스템 보안:** 서버 구축 및 관리 설정, Buffer Overflow(BoF), 로그 관리, 쉘 스크립트 등
* **웹 보안:** 웹 공격 탐지 및 로그 분석, 모의해킹, CTF, 워게임, OWASP 기반 대응 등

## 3. OSI 7 계층 및 TCP/IP 모델

### OSI 7 계층

데이터 송신 시 **캡슐화(Encapsulation)** 과정을 거치며, 수신 시 **역캡슐화(De-encapsulation)** 과정을 거칩니다.

| 계층 | 이름 | 데이터 단위 | 주요 역할 및 특징 |
| --- | --- | --- | --- |
| **L7** | **응용 (Application)** | Data | 사용자 인터페이스 제공, 인터넷 서비스 지원 |
| **L6** | **표현 (Presentation)** | Data | 데이터 표현 방식 정의, 암호화, 압축 |
| **L5** | **세션 (Session)** | Data | 통신 연결 관리, 토큰 제어, 동기화 |
| **L4** | **전송 (Transport)** | Segment | 단대단(End-to-End) 통신, 흐름 제어, TCP/UDP |
| **L3** | **네트워크 (Network)** | Packet | 라우팅(경로 설정), 논리적 주소(IP) 관리, L3 장비 |
| **L2** | **데이터링크 (Data Link)** | Frame | 물리적 전송 오류 제어 및 흐름 제어, MAC 주소, L2 장비 |
| **L1** | **물리 (Physical)** | Bit | 물리적 매체 명세, 전송 속도, 클록 동기화, L1 장비 |

## 4. 전송 프로토콜 및 제어 프로토콜

### TCP vs UDP

* **TCP:** Handshake 과정을 거침 (연결 지향), 신뢰성 높음, 전송 속도 상대적으로 느림
* **UDP:** Handshake 과정 없음 (비연결 지향), 신뢰성 낮음, 전송 속도 빠름 (스트리밍, 실시간 게임 등)

### 주소 체계 및 변환

계층별로 통신에 필요한 주소 체계가 다릅니다.

* **L2 계층:** 물리적 주소 (MAC 주소)
* **L3 계층:** 논리적 주소 (IP 주소)
* **L4 계층:** 프로세스 식별 주소 (Port 번호)

### 제어 프로토콜

* **ARP (Address Resolution Protocol):** IP 주소를 MAC 주소로 변환
* **RARP (Reverse ARP):** MAC 주소를 IP 주소로 변환
* **ICMP (Internet Control Message Protocol):** 네트워크 오류 보고 및 상태 메세지 전송 (`ping` 등)
* **IGMP (Internet Group Management Protocol):** 멀티캐스트 그룹 관리

## 5. IP 주소 체계 (IPv4 / IPv6)

* **IPv4:** 32bit / 8비트씩 4옥텟으로 나누어 10진수로 표기
* **IPv6:** 128bit / 16진수로 표기

### IPv4 클래스 분류

| 클래스 | 시작 옥텟 | 주소 범위 | 사설 IP 대역 (Private) | 주요 특수 용도 |
| --- | --- | --- | --- | --- |
| **A** | 1~126 | 1.0.0.0 ~ 126.255.255.254 | 10.0.0.0/8 | `0.0.0.0/8` (자체 네트워크) |
| **B** | 128~191 | 128.0.0.1 ~ 191.255.255.254 | 172.16.0.0/12 | `169.254.0.0/16` (링크 로컬 주소) |
| **C** | 192~223 | 192.0.0.1 ~ 223.255.255.254 | 192.168.0.0/16 | `192.0.2.0/24` (문서/예제용) |
| **D** | 224~239 | 224.0.0.1 ~ 239.255.255.254 | 멀티캐스트 전용 | `192.88.99.0/24` (6to4 릴레이) |
| **E** | 240~255 | 240.0.0.1 ~ 255.255.255.254 | 연구/실험용 | `198.18.0.0/15` (벤치마크 테스트) |

* **루프백 주소 (Loopback):** `127.0.0.0/8` (대표적으로 `127.0.0.1`, 로컬 호스트 자가 진단용)

## 6. 전송 방식 (Unicast / Multicast / Anycast / Broadcast)

* **유니캐스트 (Unicast):** 1:1 통신. 명확한 단일 수신자에게 전송
* **브로드캐스트 (Broadcast):** 1:All 통신. 동일 네트워크(서브넷) 내의 모든 호스트에게 전송
* **멀티캐스트 (Multicast):** 1:N 통신. 특정 그룹에 가입된 여러 호스트에게만 전송
* **애니캐스트 (Anycast):** 1:1 중에서 가장 가까운 수신자 전송. 동일한 주소를 가진 여러 호스트 중 물리적/논리적으로 가장 가까운 노드로 전달 (IPv6 지원)

## 7. 서브네팅과 슈퍼네팅

* **서브네팅 (Subnetting):**
* 하나의 대형 네트워크를 서브넷 마스크를 이용하여 복수의 세부 네트워크(서브넷)로 분할하는 기술
* VLAN 구성 시 네트워크를 분리하거나 IP 주소 낭비를 방지하기 위해 사용


* **슈퍼네팅 (Supernetting):**
* 여러 개의 소형 클래스 C 네트워크 대역을 하나로 합쳐서 하나의 큰 네트워크로 다루는 기술 (CIDR 방식)



---

## 8. 사설 IP, NAT, VPN

* **사설 IP (Private IP):**
* 내부 네트워크 안에서만 중복되어 사용할 수 있는 주소
* 공인 인터넷 망(외부)으로 직접 나갈 수 없음


* **NAT / PAT (Network Address Translation):**
* 사설 IP 주소를 공인 IP 주소로 변환하여 외부 인터넷과 통신할 수 있도록 해주는 기술


* **사설망 및 VPN:**
* **사설망:** 외부망과 격리하여 보안성을 확보한 내부 네트워크
* **가상 사설망 (VPN):** 공중망(인터넷)을 암호화 터널링 기술을 이용해 전용 사설망처럼 안전하게 사용하는 기술

## 9. 네트워크 관리의 5대 요소 (FCAPS)

1. **장애 관리 (Fault Management):** 네트워크 오류 및 장애 탐지, 격리, 복구
2. **구성 관리 (Configuration Management):** 장비 설정, 토폴로지 변경, 장비 상태 기록 및 관리
3. **계정 관리 (Accounting Management):** 사용자별 네트워크 자원 사용량 측정 및 과금 관리
4. **성능 관리 (Performance Management):** 트래픽 양, 응답 시간, 수신율 등 성능 지표 측정 및 측정치 분석
5. **보안 관리 (Security Management):** 네트워크 접근 제어, 데이터 암호화, 인증 및 침입 방지

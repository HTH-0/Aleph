/디렉토리 하위 폴더
/bin: 일반 사용자 및 관리자가 사용하는 기본 필수 실행 명령어 (ls, cd, cp 등)
/sbin: 시스템 관리자(root) 전용 시스템 관리/복구 명령어 (fdisk, reboot 등)
/boot: 리눅스 부팅에 필요한 핵심 파일 (커널 이미지, GRUB 설정 등)
/etc: 시스템 전체의 제어 및 프로그램 설정 파일 (네트워크, 계정 정보 등)
/home: 일반 사용자들의 개인 홈 디렉토리 (예: /home/user1)
/root: 최고 관리자(root) 전용 개인 홈 디렉토리
/lib / /lib64: /bin과 /sbin 명령어 실행에 필요한 공유 라이브러리 파일 (64비트 전용은 /lib64)
/usr: 일반 프로그램, 라이브러리, 문서 등이 설치되는 2차 소프트웨어 저장소 (윈도우의 Program Files)
/var: 시스템 운영 중 변하는 가변 데이터 (로그 파일, 메일, 캐시 등)
/dev: 하드디스크, 키보드, 마우스 등 장치(Device) 파일
/proc: 현재 실행 중인 프로세스와 메모리 정보가 담긴 가상 디렉토리 (RAM에 존재)
/sys: 커널과 장치/드라이버의 상세한 상태 정보를 제공하는 가상 디렉토리
/mnt: 관리자가 다른 장치(추가 하드, 외장하드 등)를 임시로 연결(마운트)하는 디렉토리
/media: USB, CD-ROM 등 탈부착 가능한 매체가 자동 연결되는 디렉토리
/opt: 외부 3사(Third-party) 상용 응용 프로그램 설치 디렉토리
/srv: FTP, Web 등 시스템이 제공하는 서비스의 실제 데이터 저장소
/tmp: 모든 사용자가 자유롭게 쓰는 임시 파일 저장소 (재부팅 시 삭제될 수 있음)
/run: 부팅 이후 현재 실행 중인 시스템 서비스의 상태 데이터 저장소 (RAM에 존재)
/afs: 네트워크 분산 파일 시스템인 Andrew File System 전용 연결 포인트

vi 편집기

명령 모드 (Command Mode): 처음 파일을 열었을 때 상태. 이동, 삭제, 복사 가능 (글자 입력 불가)
입력 모드 (Insert Mode): 실제로 글자를 작성하고 수정하는 상태
콜론 모드 (Last Line Mode): 저장, 종료, 검색 등을 수행하는 상태

열기: vi 파일명 (예: vi test.txt)
글자 쓰기: i 키를 눌러 입력 모드로 전환 (화면 아래 -- INSERT -- 확인 후 작성)
작성 완료: Esc 키를 눌러 명령 모드로 복귀
저장 및 종료: :wq 입력 후 Enter

입력 모드 전환 (명령 모드에서 누름)
a: Append (커서 뒤에 덧붙이기)
i: Insert현재 커서 위치에서 입력 시작
o: 현재 줄 아래에 새로운 줄을 만들며 입력 시작

삭제 및 복사 (명령 모드)
x: 커서 위치의 글자 1개 삭제 (Delete 역할)
dd: 현재 줄 전체 삭제 (잘라내기)
yy: 현재 줄 전체 복사
p: 복사/잘라낸 내용 커서 아래에 붙여넣기
u: 이전 작업 취소 (Ctrl + Z 역할)

저장 및 종료 (명령 모드에서 : 입력)
:w: 저장만 하기
:q: 종료하기 (수정 사항이 없을 때)
:wq: 저장하고 종료하기 (가장 많이 씀)
:q!: 저장하지 않고 강제 종료하기
:set nu : 라인 번호를 볼 수 있다

find :	1. 이름으로 찾기 (-name)
		find / -name "nginx.conf" $\rightarrow$ 최상위(/)부터 이름이 정확히 nginx.conf인 파일 검색
		find . -name "*.log" $\rightarrow$ 현재 폴더에서 확장자가 .log로 끝나는 모든 파일 검색
		find . -iname "*.png" $\rightarrow$ -iname을 쓰면 대소문자 구분 없이 검색 (.PNG, .png 모두 포함)

	2. 종류(타입)로 구분해서 찾기 (-type)
		find . -type f -name "test*" $\rightarrow$ 이름이 test로 시작하는 일반 파일(f)만 검색
		find . -type d -name "test*" $\rightarrow$ 이름이 test로 시작하는 디렉토리(d)만 검색

	3. 파일 크기(용량)로 찾기 (-size)
		find /var/log -size +100M $\rightarrow$ /var/log 폴더에서 100MB 이상인 대용량 파일 검색
		find . -size -1k $\rightarrow$ 현재 위치에서 1KB 미만인 파일 검색4. 수정 시간으로 찾기 (-mtime)
		find . -mtime -7 $\rightarrow$ 최근 7일 이내에 수정된 파일 검색find . -mtime +30 $\rightarrow$ 수정된 지 30일이 지난 오래된 파일 검색5. 찾은 파일에 특정 명령어 실행하기 (-exec)
		find . -name "*.tmp" -exec rm -f {} \;$\rightarrow$ .tmp 확장자를 가진 파일들을 찾아 삭제(rm -f)를 바로 실행합니다. ({}는 찾은 파일을 의미하며 \;로 구문을 마칩니다.)

>> type 자료형 종류


1. 문자 자료형 (String)
 	CHAR(N)    : 고정 길이 문자열 (주민번호, 전화번호)
	VARCHAR(N) : 가변 길이 문자열 (이름, 아이디, 주소) 
	TEXT       : 매우 긴 장문 텍스트 (게시글 본문)

2. 숫자 자료형 (Numeric)
	INT        : 일반 정수 (-21억 ~ 21억) *가장 많이 사용
	BIGINT     : 대용량 정수 (회원번호, 결제금액)
	DECIMAL    : 정확한 소수점 실수 (금융/금전 데이터)

3. 날짜/시간 자료형 (Date & Time)
	DATE       : YYYY-MM-DD (생년월일)
	DATETIME   : YYYY-MM-DD HH:MM:SS (작성일, 로그인시간)

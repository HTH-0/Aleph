왼쪽 라우터(본사)

interface tunnel 100[임의의 번호]

ip address 10.10.0.1 255.255.255.0

tunnel mode gre ip
>> 터널의 동작 방식(캡슐화 방식)을 GRE over IPv4로 지정
>>tunnel mode gre / ipv6ip
	GRE: 이것저것 다 들어가는 만능 택배 상자 (가장 많이 씀, OSPF 등 라우팅도 가능)
	ipv6ip: 오직 IPv6 패킷만 쏙 넣어서 전달하는 전용 봉투 (헤더가 살짝 가벼움)

tunnel source serial 0/3/0
>> 출발지(Source) 물리 인터페이스를 지정

tunnel destination 2.2.2.2
>> 목적지(Destination) 공인 IP 주소

ip route 172.16.0.0 255.255.255.0 10.10.10.2
>>원격지 사설망(172.16.0.0/24)으로 가는 트래픽을 VPN 터널 입구(상대방 터널 IP: 10.10.10.2)로 밀어 넣어주는 정적 라우팅 설정

오른쪽 라우터 (지사)

interface tunnel 100
가상의 터널 인터페이스(Tunnel 100)를 생성하고 해당 설정 모드로 진입

ip address 10.10.10.2 255.255.255.0
가상 터널 내부에서 사용할 내 라우터의 IP 주소를 부여

tunnel mode gre ip
터널의 동작 방식(캡슐화 방식)을 GRE over IPv4로 지정

tunnel source serial 0/3/1
터널 패킷이 실제로 나갈 내 라우터의 물리 포트(출발지)를 지정

tunnel destination 1.1.1.1
터널이 연결될 반대편 라우터의 실제 공인 IP 주소(목적지)를 지정

ip route 192.168.100.0 255.255.255.0 10.10.10.1
원격지 사설망(192.168.100.0/24)으로 가는 트래픽을 VPN 터널 입구(상대방 터널 IP: 10.10.10.1)로 밀어 넣어주는 정적 라우팅 설정

Access-List 설정 / Crypto 정책 설정 / Crypto map 설정 / Interface에 Map 적용

access-list 100 permit gre host 1.1.1.1 host 2.2.2.2

access-list 100 permit gre 192.168.100.0 0.0.0.255 host 2.2.2.2

crypto isakmp policy 10
ISAKMP 정책 우선순위 10번을 생성하고 해당 설정 모드로 진입

authentication pre-share
라우터 상호 인증 방식을 사전 공유키(Pre-Shared Key, 비밀번호) 방식으로 지정

encryption 3des
데이터 암호화 알고리즘으로 3DES(Triple DES)를 사용

hash md5
해시 알고리즘으로 MD5를 사용

crypto isakmp key 1234 address 2.2.2.2
IP 주소가 2.2.2.2인 상대방 라우터와 인증할 비밀번호(Pre-Shared Key)를 1234로 지정

crypto ipsec transform-set test esp-3des esp-md5-hmac
test라는 이름의 IPsec 암호화 세트(Transform-Set)를 만들고, 암호화 방식으로 esp-3des, 무결성 검증 방식으로 esp-md5-hmac을 지정

crypto map vpn-map 10 ipsec-isakmp
vpn-map이라는 이름의 크립토 맵 10번 항목을 만들고 설정 모드로 진입

match address 100
암호화할 트래픽 조건으로 Access-List 100번을 지정

set peer 2.2.2.2
암호화된 패킷을 받아줄 상대방 라우터의 IP를 2.2.2.2로 지정

set transform-set test
실제 데이터를 암호화할 때 방금 만들어둔 test 암호화 세트를 사용하도록 지정

interface serial 0/3/0

crypto map vpn-map
방금 전까지 조립했던 vpn-map이라는 이름의 크립토 맵을 이 포트에 최종 적용

L2 스위치의 특징 및 IP 설정
물리 포트 IP 부여 불가: L2 스위치는 포트를 라우터 포트로 바꾸는 no switchport 명령어를 지원하지 않습니다.
원격 관리용 IP(SVI) 활용: 물리 포트가 아닌 Virtual LAN 인터페이스(interface vlan 1)에 IP를 설정하여 Telnet, SSH, Ping 등 스위치 관리 및 원격 접속 목적으로 사용합니다.
VLAN Up 조건: interface vlan 1에 IP를 넣고 no shutdown을 해도, 스위치 물리 포트에 장비(PC, 라우터 등)가 꽂혀 포트가 작동해야만 VLAN 인터페이스 상태가 최종적으로 UP 상태로 바뀝니다.

L3 스위치의 특징 및 라우팅 설정
물리 포트 IP 부여 가능: 물리 포트에 들어가 no switchport를 입력하면 스위치 포트가 L3 라우팅 포트로 전환되어 라우터처럼 포트에 직접 IP를 할당할 수 있습니다.
IP 라우팅 활성화 필수: L3 스위치는 기본적으로 라우터 기능이 꺼져 있으므로, 전역 모드에서 ip routing 명령어를 먼저 입력해야 OSPF 같은 라우팅 프로토콜을 설정하고 경로를 교환할 수 있습니다.

### [Cisco] Line (제어 통로) 개념 및 설정 요약

#### 1. Line의 기본 개념

* **정의:** 관리자가 장비에 접속하여 명령어를 치고 **제어하기 위한 전용 통로**
* **역할:** 접속 방식 및 동시 접속자 수에 따라 보안(비밀번호, 로그인 방식)과 환경을 설정하는 공간

---

#### 2. Line의 주요 종류 (접속 방식에 따른 구분)

| 구분 | **Line Console (`line con 0`)** | **Line VTY (`line vty 0 4`)** |
| --- | --- | --- |
| **접속 방식** | 물리적 콘솔 케이블 직접 연결 | IP 네트워크를 통한 원격 접속 (Telnet / SSH) |
| **주요 용도** | 초기 세팅, 네트워크 장애 시 **비상 복구 통로** | 평소 멀리서 네트워크로 장비를 관리하는 **일상 통로** |
| **IP 필요 여부** | IP 설정 없이도 접속 가능 | IP 설정 및 통신이 가능해야 함 |
| **통로 개수** | 딱 **1개** (`line con 0`) | 기본 수십~수백 개 중 선택 지정 (예: `0 4` = 5개) |

---

#### 3. 핵심 세부 개념 정리

* **`vty` (Virtual Teletype):** 변경할 수 없는 고정 키워드이며, "가상 원격 접속 통로"를 의미함.
* **`0 4` (통로 범위):** 0번부터 4번까지 **동시 접속자 5명**을 허용하겠다는 의미.
* 범위 확장 시(예: `0 7`로 재입력), 통로가 8개로 늘어나며 이전 중복 라인은 새로운 설정으로 **덮어쓰기(Override)** 됨.


* **구조적 원리:** IP 주소(장비) $\rightarrow$ Port 22/23(현관문) $\rightarrow$ **Line VTY(내부 세부 창구)**
* 여러 사용자가 포트 하나로 들어와도 서로 섞이지 않도록 내부에서 라인(Line) 단위로 1:1 세션을 나누어 제어함.



---

#### 4. 필수 명령어 예시

```text
Router(config)# line console 0          ! 콘솔(물리 접속) 설정 진입
Router(config)# line vty 0 4            ! 원격(VTY 0~4번) 설정 진입

Router(config-line)# password cisco123  ! 접속 비밀번호 설정
Router(config-line)# login              ! 접속 시 비밀번호 검증 활성화
Router(config-line)# logging synchronous! 입력 중 로그 메시지 방해 차단 (실무 필수)
Router(config-line)# exec-timeout 10 0  ! 10분 동안 입력 없으면 자동 로그아웃

```

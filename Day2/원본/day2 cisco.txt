gateway

config 모드에서
interface gi0/0  : GigabitEthernet 0/0 포트(인터페이스)를 설정할 수 있는 하위 설정 모드로 진입
ip address 192.168.16.1 255.255.255.0 : 해당 포트(인터페이스)에 ipv4 주소, 서브넷마스크 주소를 할당한다.
no shutdown : 포트를 활성화시킨다. ( 셧다운(끄기)를 취소 ) >> 기본값이 shutdown 임
	>> 초록색 선으로 바뀐다.


pc0, pc1 > desktop > ip configuration 에서 default Gateway 를 192.168.16.1 로 변경 >>아까 설정한 라우터와 연결하기 위함
domain 없이도 연결 가능 > 편리하게 연결하기 위함


사용 가능한 ip 대역대
192.168.16.0~192.168.16.255

192.168.16.0 는 네트워크 주소 (집주소)
192.168.16.255 는 브로드캐스팅 주소

실제 할당 가능한 주소는 위 2개를 제외한 254개

24란 ? : bit의 개수

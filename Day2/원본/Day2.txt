osi 표준모델

물리 계층 - 전송 매체의 물리적 인터페이스 사항(데이터의 전송 속도, L1 장비, 클록 동기화, 물리적 연결 형태 등) , 데이터 표현단위 : bit(0/1)
데이터링크 계층 - 물리적 전송 오류 해결(전송 기능, 흐름 제어), L2 장비
네트워크 계층 - 라우팅 문제 해결, L3 장비, 경로 설정하는 부분
전송 계층 - 단대단 통신 기능(흐름 제어), 전송이 실제로 일어나는 부분, tcp/udp
세션 계층 - 통신 연결 관리(토큰제어, 동기화)
표현 계층 - 데이터의 의미와 표현 방법(암호화, 압축)
응용 계층 - 사용자 인터페이스 제공(사용자층의 인터넷 서비스 지원)

>> 위로 갈수록 캡슐화(Encapsulation) 아래로 갈수록 역 캡슐화(De-encapsulation)
>>> 보내는쪽은 캡슐화 과정, 받는쪽은 역캡슐화 과정

tcp : handshaking 과정을 한다
	>신뢰성 높음, 전송 속도 느림 
udp : handshaking 없음
	>신뢰성 낮음, 전송 속도 빠름 >> 스트리밍, 게임 같은곳

ip : 전송하는 과정에서 주소 역할을 한다.

물리적 주소 mac > 2계층에서 인지함
논리적 주소 ip


계층마다 주소가 다 다름 (2계층 mac, 3계층 ip, 4계층 포트)
>>> 주소를 변환한다

arp : ip주소를 mac 주소로
rarp :mac 주소를 ip 주소로

icmp : 메세지 프로토콜
igmp : 그룹 메세지 프로토콜

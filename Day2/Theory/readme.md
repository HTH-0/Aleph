# [Theory] 네트워크 기초 이론 및 통신 모델

---

### 1. IT 인프라 및 정보 보안 기초

**역할 정의**
* **서버 (Server):** 정보를 제공하는 주체
* **클라이언트 (Client):** 정보를 요청하는 주체

**IT 인프라 구성요소**
* 하드웨어, 소프트웨어, 데이터센터, 클라우드 서비스, 네트워크
* **클라우드 서비스:** 물리적 하드웨어 직접 구축 없이 전문 기업의 데이터센터 자원을 인터넷으로 임대
* **SaaS:** 별도 설치 없이 웹 브라우저를 통해 사용하는 소프트웨어 구독/월세 모델

**정보 보안의 3대 요소 (CIA)**
* **기밀성 (Confidentiality)**
* **무결성 (Integrity)**
* **가용성 (Availability)**

**정보 보안의 3가지 분류**
* **관리적 보안 / 물리적 보안**
* **기술적 보안 (핵심):**
  * 네트워크 보안 (Switching, Routing, ACL, VPN, NAT, Firewall, DDoS)
  * 시스템 보안 (서버 설정, BoF, 로그 관리, 셸 스크립트)
  * 웹 보안 (웹 취약점 진단, 모의해킹, OWASP Top 10)

### 2. 네트워크 통신 모델 (OSI 7계층 & TCP/IP)

**OSI 7계층 정의**
* **7계층 (응용, Application):** 사용자 인터페이스 및 애플리케이션 서비스 지원
* **6계층 (표현, Presentation):** 데이터 표현 형식 정의, 암호화, 압축
* **5계층 (세션, Session):** 통신 세션 수립, 유지, 동기화
* **4계층 (전송, Transport):** 단대단(End-to-End) 신뢰성 있는 데이터 전송 (TCP/UDP)
* **3계층 (네트워크, Network):** 논리 주소(IP) 기반 최적 경로 설정(Routing)
* **2계층 (데이터링크, Data Link):** 물리 주소(MAC) 기반 인접 노드 간 전송 및 오류 제어
* **1계층 (물리, Physical):** 케이블 인터페이스 규격 및 비트(0/1) 전기 신호 전송

> **데이터 가공 방식**
> * **캡슐화 (Encapsulation):** 송신 측 (상위 계층 ➔ 하위 계층 헤더 추가)
> * **역캡슐화 (De-encapsulation):** 수신 측 (하위 계층 ➔ 상위 계층 헤더 제거)

**OSI vs TCP/IP 계층 매핑**

| OSI 7 Layer | PDU (단위) | TCP/IP Model | 주요 프로토콜 |
| :--- | :--- | :--- | :--- |
| **Application**<br>**Presentation**<br>**Session** | Data | **Application** | HTTP, HTTPS, FTP, TELNET, SMTP, DNS |
| **Transport** | Segment | **Transport** | TCP (Handshake 신뢰성), UDP (비연결성 고속) |
| **Network** | Packet | **Internet** | IP, ICMP, IGMP, ARP, RARP |
| **Data Link** | Frame | **Network Access** | Ethernet, MAC |
| **Physical** | Bit | | |

### 3. IP 주소 체계 및 서브넷

**IPv4 주소 클래스 (32bit)**

| 클래스 | 시작 옥텟 | 전체 주소 범위 | 사설 IP 대역 | 비고 / 특수 목적 |
| :--- | :--- | :--- | :--- | :--- |
| **A** | 1 ~ 126 | `1.0.0.0` ~ `126.255.255.254` | `10.0.0.0/8` | `127.0.0.0/8` (루프백 테스트) |
| **B** | 128 ~ 191 | `128.0.0.1` ~ `191.255.255.254` | `172.16.0.0/12` | `169.254.0.0/16` (링크 로컬 APIPA) |
| **C** | 192 ~ 223 | `192.0.0.1` ~ `223.255.255.254` | `192.168.0.0/16` | `192.0.2.0/24` (문서/예제용) |
| **D** | 224 ~ 239 | `224.0.0.1` ~ `239.255.255.254` | - | 멀티캐스트 전용 |
| **E** | 240 ~ 255 | `240.0.0.1` ~ `255.255.255.254` | - | 실험 및 연구용 |

**데이터 전송 방식**
* **유니캐스트:** 1:1 통신
* **브로드캐스트:** 1:All 동일 대역 전체 통신
* **멀티캐스트:** 1:Group 특정 그룹 통신
* **애니캐스트:** 1:1 가장 가까운 노드 통신 (IPv6)

**IP 대역 및 Prefix 계산 (`192.168.16.0/24`)**
* **Prefix (`/24`):** 서브넷 마스크 비트 1이 24개(`255.255.255.0`)
* **네트워크 주소:** `192.168.16.0` (대표 주소, 호스트 사용 불가)
* **브로드캐스트 주소:** `192.168.16.255` (전체 전송 주소, 호스트 사용 불가)
* **유효 호스트 IP:** `192.168.16.1` ~ `192.168.16.254` (총 254개)

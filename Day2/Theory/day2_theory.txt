2. 네트워크 통신 모델 (OSI 7계층 & TCPIP)

[OSI 7계층 정의]

 7계층 (응용, Application) 사용자 인터페이스 제공, 인터넷 서비스 지원
 6계층 (표현, Presentation) 데이터의 의미와 표현 방식 정의, 암호화, 압축
 5계층 (세션, Session) 통신 연결 관리, 토큰 제어, 동기화
 4계층 (전송, Transport) 단대단(End-to-End) 통신 제어, 흐름 제어, TCPUDP
 3계층 (네트워크, Network) 경로 설정(라우팅), L3 장비
 2계층 (데이터링크, Data Link) 물리적 전송 오류 해결, 흐름 제어, L2 장비
 1계층 (물리, Physical) 전송 매체의 물리적 인터페이스(전송 속도, 클록 동기화, 물리적 연결 형태), 데이터 단위 Bit(01)

 캡슐화 (Encapsulation) 상위 계층에서 하위 계층으로 내려가며 헤더를 붙이는 과정 (송신 측)
 역캡슐화 (De-encapsulation) 하위 계층에서 상위 계층으로 올라가며 헤더를 제거하는 과정 (수신 측)

## [OSI vs TCPIP 계층 매핑 및 프로토콜]

## OSI 모델         데이터 단위     TCPIP 모델           주요 프로토콜

## Application
Presentation    Data            Application           FTP, TELNET, SMTP, HTTP, SNMP 등
Session

## Transport       Segment         Transport             TCP, UDP

## Network         Packet          Internet              IP, ICMP, IGMP

## Data Link       Frame           Network Access (Link) Network Interface (Ethernet)
Physical        Bit

[주요 프로토콜 및 계층별 주소 체계]

 TCP 3-way Handshaking 수행 - 신뢰성 높음, 전송 속도 상대적 느림
 UDP Handshaking 없음 - 신뢰성 낮음, 전송 속도 빠름 (실시간 스트리밍, 게임 등)
 IP 패킷 전송 시 목적지를 식별하는 논리적 주소 역할
 계층별 식별 주소
 2계층 MAC 주소 (물리적 주소)
 3계층 IP 주소 (논리적 주소)
 4계층 Port 번호 (프로세스 식별)


 주소 변환 및 제어 프로토콜
 ARP (Address Resolution Protocol) IP 주소를 MAC 주소로 변환
 RARP (Reverse ARP) MAC 주소를 IP 주소로 변환
 ICMP (Internet Control Message Protocol) 네트워크 상태 및 오류 제어 메시지 전송
 IGMP (Internet Group Management Protocol) 멀티캐스트 그룹 관리

3. IPv4 주소 체계 및 데이터 전송 방식

[IPv4 주소 클래스 구조 (32bit, 10진수 표기)]

 참고 IPv6는 128bit 체계이며 16진수로 표기함

---

## 클래스  시작 옥텟  전체 주소 범위                  사설 IP 대역     특수 용도 및 예약 주소

## A       1~126      1.0.0.0 ~ 126.255.255.254       10.0.0.08       0.0.0.08 (자체 네트워크)
127.0.0.08 (로컬 루프백 테스트)
B       128~191    128.0.0.1 ~ 191.255.255.254     172.16.0.012    169.254.0.016 (APIPA 링크 로컬)
C       192~223    192.0.0.1 ~ 223.255.255.254     192.168.0.016   192.0.2.024 (문서예제용)
D       224~239    224.0.0.1 ~ 239.255.255.254     (멀티캐스트용)   192.88.99.024 (6to4 릴레이)
E       240~255    240.0.0.1 ~ 255.255.255.254     (연구미래 예약) 198.18.0.015 (장비 벤치마킹 테스트)

[데이터 전송 방식]

 유니캐스트 (Unicast) 11 통신 (특정 단일 목적지로 데이터 전송)
 브로드캐스트 (Broadcast) 1All 통신 (동일 네트워크 내 모든 호스트로 데이터 전송)
 멀티캐스트 (Multicast) 1Group 통신 (특정 그룹에 가입된 호스트들에게만 전송)
 애니캐스트 (Anycast) 11 (가장 가까운 노드) 통신 (IPv6 지원, 가장 가까운 단일 인터페이스로 전송)

[IP 대역 구조 및 서브넷 표기]

 192.168.16.124 표기에서 '24' (Prefix) 서브넷 마스크 비트 수 (255.255.255.0)
 대역 범위 192.168.16.0 ~ 192.168.16.255 (총 256개)
 네트워크 주소 192.168.16.0 (호스트 식별 시작 주소, 대표 주소)
 브로드캐스트 주소 192.168.16.255 (해당 네트워크 전체 전달용 주소)
 실제 호스트 할당 가능 주소 192.168.16.1 ~ 192.168.16.254 (총 254개)

4. 토폴로지 및 물리 케이블 규격

[토폴로지 (Topology)]

 물리적 토폴로지 (Physical Topology) 실제 케이블 및 장비가 배치된 물리적 형태
 논리적 토폴로지 (Logical Topology) 데이터가 장비 사이를 이동하는 논리적 경로

[케이블 연결 방식]

 다이렉트 케이블 (Direct-through Cable) 서로 다른 종류의 장비 간 연결 (이종 장비 PC-스위치, 스위치-라우터 등)
 크로스오버 케이블 (Cross-over Cable) 서로 같은 종류의 장비 간 연결 (동종 장비 PC-PC, 스위치-스위치, 라우터-라우터 등)

[네트워크 범위]

 LAN (Local Area Network) 2계층 및 그 이하 장비로 묶인 근거리 통신망
 WAN (Wide Area Network) 지리적으로 떨어진 LAN과 LAN을 3계층 이상 장비로 연결한 광역 통신망

[포트 링크 상태 색상]

 초록색 정상 연결 (Link Up)
 주황색 (오렌지) 통신 연결 협상 및 시도 중 (STP 수렴 과정 등)
 빨간색 물리적논리적 단선 상태 (Link Down  Shutdown)

5. 시스코 스위치 기초 실습 (Layer 2)

[스위치 상태 확인 명령어]

 enable 특권 모드(Privileged Mode) 진입
 show  현재 모드에서 실행 가능한 명령어 목록 조회
 show mac-address-table 스위치가 학습한 전체 MAC 주소 테이블 확인

[PC IP 구성 및 2계층 통신 검증]

 PC1 (Desktop  IP Configuration) Static 설정, IP 192.168.16.100  Subnet 255.255.255.0
 PC2 (Desktop  IP Configuration) Static 설정, IP 192.168.16.200  Subnet 255.255.255.0
 PC1 커맨드 프롬프트에서 `ping 192.168.16.200` 실행
 스위치는 물리적으로 동일 대역에 연결되어 있다면 2계층 수준에서 바로 통신 가능
 통신 성공 후 `show mac-address-table`을 확인하면 각 포트에 동적(Dynamic)으로 매핑된 MAC 주소가 등록됨


 TTL (Time To Live) 패킷이 네트워크 상에서 생존 가능한 시간홉 수. 라우터(L3)를 거칠 때마다 1씩 감소하며, 0이 되면 패킷을 폐기하여 무한 루프를 방지함.

6. 시스코 라우터 기초 설정 및 CLI 조작

[모드 전환 단계]

1. 사용자 모드 (User Mode) Router
 진입 초기 접속 시
 명령어 `enable` 입력 시 특권 모드로 전환


2. 특권 모드 (Privileged Mode) Router#
 진입 Router 상태에서 `enable`
 역할 시스템 상태 조회, 저장, 재부팅 등 관리자 권한 작업
 명령어 `configure terminal` 입력 시 전역 설정 모드로 전환


3. 전역 설정 모드 (Global Configuration Mode) Router(config)#
 진입 Router# 상태에서 `configure terminal`
 역할 장비 전체에 영향을 미치는 파라미터 구성 (호스트명, 계정, 라우팅 등)



[CLI 편의 단축키 및 명령어 축약]

 명령어 축약 `configure terminal` - `conf t`, `enable` - `en`
 자동 완성 Tab 키
 도움말 명령어 뒤에 `` 입력 시 사용 가능한 하위 인자 확인
 화면 출력 제어 Enter (한 줄씩 스크롤), Spacebar (한 페이지씩 스크롤)
 상위 모드 즉시 복귀 Ctrl + Z 또는 `end` (어느 하위 모드에서든 Router# 상태로 즉시 이동)
 한 단계 상위 모드 복귀 `exit`

[기본 환경 설정]

 초기 설정 대화창 건너뛰기 최초 구동 시 `Continue with configuration dialog [yesno]`에서 `no` 입력
 호스트명 변경
Router(config)# hostname A-R

[설정 저장 및 메모리 관리]

 Running-config 현재 활성화되어 동작 중인 설정값 (RAM에 저장, 재부팅 시 휘발)
 Startup-config 장비 부팅 시 불러오는 저장된 설정값 (NVRAM 비휘발성 메모리에 저장)
 저장 명령어 (Privileged 모드에서 실행)
1. `copy running-config startup-config` (권장 표준)
2. `write memory` (또는 `wr`)


 저장 확인 `show running-config` (RAM 확인), `show startup-config` (NVRAM 확인)

7. 시스코 장비 보안 및 Line(접속 제어 통로) 설정

[Line의 개념과 구조]

 정의 관리자가 장비에 접근하여 제어하기 위한 전용 접속 통로
 원리 외부 접근(IPPort) - 내부 세부 창구(Line)로 11 세션을 분기하여 제어
 주요 Line 구분
 Line Console (`line con 0`) 장비 콘솔 포트에 케이블을 직접 연결하는 물리 접속 통로 (단 1개만 존재, 초기 세팅 및 비상 복구용, IP 불필요)
 Line VTY (`line vty 0 4`) 네트워크를 통해 접근하는 가상 원격 접속 통로 (TelnetSSH, IP 통신 필요, 다중 동시 접속 지원)
 `0 4`의 의미 0번부터 4번까지 총 5개의 동시 접속 세션을 허용한다는 범위 지정 (예 `0 7`로 변경 시 8개로 확장되며 기존 설정은 덮어씌워짐)



[모드별 비밀번호 설정]

1. 콘솔 접속 비밀번호
A-R(config)# line console 0
A-R(config-line)# password 1234
A-R(config-line)# login
A-R(config-line)# exit
2. 원격 접속(VTY) 비밀번호
A-R(config)# line vty 0 4
A-R(config-line)# password cisco123
A-R(config-line)# login
A-R(config-line)# logging synchronous   ! 명령어 입력 중 시스템 로그 메시지 방해 차단
A-R(config-line)# exec-timeout 10 0     ! 10분 동안 입력 없을 시 자동 세션 종료
A-R(config-line)# exit
3. 특권 모드 진입 비밀번호
 일반 암호 `enable password 12345` (평문 저장)
 암호화 저장 `enable secret 123456` (해시 암호화 저장, password보다 우선 적용됨)


4. 설정 파일 내 모든 평문 비밀번호 일괄 암호화
A-R(config)# service password-encryption

8. 라우터 인터페이스 및 기본 게이트웨이(Default Gateway) 구성

[라우터 인터페이스 설정]

 라우터 포트는 기본적으로 `shutdown` 상태이므로 IP 부여 후 활성화가 필수적임

A-R(config)# interface GigabitEthernet00
A-R(config-if)# ip address 192.168.16.1 255.255.255.0
A-R(config-if)# no shutdown
A-R(config-if)# exit
(포트 링크 상태가 초록색으로 변경됨)

[PC 게이트웨이 연동]

 PC0, PC1 (Desktop  IP Configuration)
 Default Gateway 192.168.16.1 입력


 게이트웨이 역할 로컬 네트워크(LAN)를 벗어나 다른 네트워크 대역으로 나가는 통로 역할을 수행함

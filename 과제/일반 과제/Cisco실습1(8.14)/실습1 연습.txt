vlan 설정
1. ip주소를 나누고 pc에 각각 기입.
2. 스위치 config 모드에서 vlan 이름 설정
3. 스위치 각 fa포트마다 vlan pc 와 매칭
4. 스위치끼리, 라우터랑은 trunk 모드, pc랑은 access 모드로 연결
5. 라우터에 가상 게이트웨이 지정하기

----------------------------------------------------------------
vlan 과정

End Device
각 end device에 ip, subnetmask, gw 기입한다

스위치
config 에서 "vlan [vlan 포트이름]" 모드로 진입해 "name [vlan 이름]" 설정
"interface [포트이름]"로 진입해 sw mode access/trunk 설정
access 경우에는 "sw access [vlan 포트이름]"
>> en 모드에서 "show vlan brief" 로 access모드와 vlan 이름 설정 확인
>> "show interfaces trunk" 로 trunk 확인

라우터
interface gig0/0.[이름 > 해당 vlan포트 이름으로 하면 편함]
encapsulation dot1q [통일해둔 이름] >> tagging  작업 : 가상으로 하나의 물리포트를 여러개로 분리하기 위함
ip address [] []
interface gig0/0 에서 nu shutdown

>> 실수가 있었다
.10 pc에서 다른 pc로 통신이 안됨
.10 pc에서 본인 게이트웨이로 통신 시도 >> 안됨 >> 스위치 정보 확인
중앙 스위치에서 라우터로 가는 fa0/5 포트를 기입하지 않고 빠뜨림
>> show in trunk 로 확인함

EIGRP 과정

라우터
interface se0/3/0 진입
no shutdown 및 ip address 입력
config 모드에서 router eigrp [as번호]
no auto-summary
network [] [와일드카드] >> 연결된 모든 네트워크에 적용

해당 구조에서는 오른쪽을 경계로 기준으로 잡는다
as 200 에서 설정을 한다
추가로
as 100 으로 들어가서 통신회선(2.2.2.0)을 네트워크 입력하고 redistribute 200
